# sheryllazer.github.io

Portfolio site for Sheryl Lazer. Static HTML, no build step.
Live at https://sheryllazer.github.io/

| File | What it is |
|---|---|
| index.html | Homepage |
| ridehailing.html, portco-review.html, job-search-skill.html | Linked work pages |
| intro-video-v11.mp4, video-poster-v11.jpg | Intro video and its cover |
| og-v2.png | Link-preview image |
| logos/ | Employer logos |
| .nojekyll | Tells GitHub Pages to serve files as they are |

To update: replace a file in the repo (Add file → Upload files), commit, and the site refreshes in a minute or two.
